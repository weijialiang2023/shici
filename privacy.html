PRIVACY · DATA

你的学习记录，先留在你的设备里。

本说明适用于当前公开的拾词网页版。当前版本没有账号、云端同步、广告或第三方产品分析服务。

版本 31更新：2026-11-23

当前保存哪些数据

  • 昵称、学习目标、发音偏好和当前词书；
  • 学习过的词条、自评、客观题结果、复习日期、收藏和连续学习记录；
  • 浏览器持久存储申请结果、备份时间等运行状态。

这些数据保存在当前站点的浏览器 localStorage 和 IndexedDB 中。拾词网页版当前不会把这些学习记录上传到自有服务器。

本机长期服务模式

如果你使用仓库中的本机长期服务脚本，学习记录还会写入 macOS 的用户应用支持目录：

~/Library/Application Support/Shici/progress/

  • state.json：当前版本；
  • state.prev.json：上一版；
  • history/daily/：每日第一份快照；
  • history/checkpoints/：近 90 天每 6 小时快照。

该模式只在本机 127.0.0.1 提供接口，不代表公开网站具备账号或云同步。

浏览器、托管和语音服务

  • GitHub Pages 负责托管公开网页，可能按照其自身政策处理访问请求、IP 地址和错误日志；
  • Service Worker 会在浏览器中缓存网页和词书资源，以便离线打开；
  • 朗读功能调用浏览器或操作系统的语音合成能力；拾词应用本身不会把朗读文本发送到自有服务器，具体语音能力及数据处理由浏览器或操作系统决定。

拾词当前没有接入广告、用户画像或第三方行为分析服务。版本 31 内置了一个默认关闭的匿名事件接口：未配置接收端点、未取得明确同意时，事件只在浏览器内部发出，不会上传。

反馈页面

GitHub Issue 是公开页面。不要在反馈中填写姓名、手机号、住址、账号密码或完整学习备份。

反馈页默认只根据你填写的内容生成报告。只有主动勾选“附带匿名诊断摘要”时，报告才会加入应用版本、浏览器摘要、视口、当前词书和记录 schema。

  • 报告不会自动上传；
  • 点击“复制报告”只写入系统剪贴板；
  • 点击“打开 GitHub Issue”会把预览中的报告带到 GitHub，是否发布由你确认。

删除和迁移

  • 在学习设置中点击“清除所有学习记录”可清除当前浏览器的拾词记录；
  • 在浏览器设置中清除本站点数据也会删除本地记录；
  • 使用“导出当前记录”迁移或备份，再在另一设备使用“导入备份”；
  • 本机长期服务产生的文件需要由用户自行删除。

由于当前没有账号，拾词无法从服务器代为恢复已经丢失的浏览器本地记录。
