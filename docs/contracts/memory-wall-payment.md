# 记忆墙打印包：产品、授权与交付

## 产品边界

- 产品名：记忆墙打印包。
- 类型：一次性付费的长期使用授权，不是自动续费订阅。
- 展示价格：首发 `¥19`，常规 `¥29`。
- 免费试用：未购买时可打印 3 张预览卡，带“预览”标记。
- 完整权益：
  - 12、24 或 40 张；
  - 便签卡、口袋条、大字墙三种 A4 版式；
  - 最近学过、待巩固、已收藏三种范围；
  - 释义、音标与词性、例句显示开关；
  - 可重复打印和另存 PDF。

## 为什么这样设计

- 卡片只用当前词书里已经学过的词，避免印刷没学过的内容。
- 默认按最近学习时间排序，适合贴到手边做短时重复遇見。
- 每张卡只保留单词、读音、核心词义和至多一条例句，降低视觉负担。
- 虚线边框用于裁切；小尺寸适合书桌和冰箱，大字墙适合衣柜、门后和书桌正前方。
- 打印建议为 A4、实际大小、开启背景图形。黑白打印机也能通过边框和字号使用。

## 授权格式

客户端使用 ECDSA P-256 / SHA-256 验签。

授权码由两段 Base64URL 组成：

```text
base64url(JSON payload) + "." + base64url(P1363 signature)
```

payload：

```json
{
  "v": 1,
  "product": "memory-wall",
  "subject": "订单号或购买者标识",
  "issuedAt": "2026-11-24T00:00:00Z",
  "expiresAt": null
}
```

公钥只存在于 `js/domain/entitlements.js`。私钥不得提交到仓库或部署目录。

当前本机签发私钥位置：

```text
/Users/weijialiang/.config/shici/memory-wall-private.pem
```

公钥 DER SHA-256：

```text
1ae6be96c2a05f778a47c1f94a3134f28c8ab3488db08cc7527f0dcbdc8d6710
```

签发授权码：

```sh
python3 tools/issue_memory_wall_license.py \
  --private-key ~/.config/shici/memory-wall-private.pem \
  --subject ORDER-20261124-0001
```

长期授权不传 `--expires-at`；需要期限时传 ISO-8601 时间。

## 购买流程

### 正式在线支付尚未接入

1. 用户在记忆墙页点击“解锁完整打印包”。
2. 购买入口为空时进入购买预登记，不收款。
3. 运营人员确认需求后，再决定支付平台、价格和退款规则。

### 接入支付链接后

在 `js/premium-config.js` 中填写 `purchaseUrl`，例如平台支付链接：

```js
purchaseUrl: 'https://支付平台生成的固定链接'
```

固定支付链接只适合单次买断或统一订单金额。接入微信/支付宝/Stripe 商户后，应改为服务端创建订单：

1. 服务端创建订单并保存订单号、金额、商品、状态。
2. 支付回调验签，更新订单状态。
3. 支付成功后生成带订单号的签名授权码。
4. 在确认页显示授权码，或发送到购买者邮箱。
5. 用户回到拾词输入授权码。
6. 退款时记录订单状态；是否远程吊销授权码需要另建撤销机制。

## 已知限制

- 当前是离线授权，不是强设备绑定。复制同一授权码仍可能在另一浏览器解锁。
- 清除浏览器站点数据后授权码会丢失，需要重新输入。
- 当前没有订单服务、退款接口和授权吊销列表。
- 当前没有在线收款。商户号、支付回调、发票和退款必须在上线收费前完成。

## 验收

- 未解锁：只出现 3 张预览卡，打印按钮进入付费弹层。
- 授权码签名错误、产品不匹配或过期时拒绝解锁。
- 有效授权码可用于 12–40 张打印和三种版式。
- 打印媒体下隐藏侧栏、工具栏和付费提示，只保留 A4 卡片页。
- 390px 页面无横向溢出，屏幕可见文本不小于 12px。
