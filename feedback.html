学习记录异常

先不要清除浏览器站点数据。清除后，当前浏览器中的学习记录可能无法恢复。

  1. 回到拾词首页，打开右上角或侧边栏的学习设置。
  2. 点击“导出当前记录”，把 JSON 文件保存到安全位置。
  3. 在反馈中描述异常发生前后的操作，不要直接公开附件内容。

GitHub Pages 版本使用浏览器本地存储，不同浏览器、设备和站点 origin 之间不会自动同步。清理浏览器数据、重装系统或更换设备前，请先导出备份。

当前支持边界

  • 当前没有账号系统和跨设备云端同步，因此无法从服务端找回全部历史记录。
  • 当前尚未配置公开支持邮箱和工单系统。大陆用户优先复制报告；GitHub Issue 只作为开发期备用渠道。
  • 内容纠错会优先处理高频考试词、释义错误、例句明显不通和目标词缺失。
  • 拾词不承诺考试分数，不替代学校教材、老师讲解或正式词典。
